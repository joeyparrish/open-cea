# SMPTE ST 334-1:2015 — VANC mapping of caption data: digest

Digest of SMPTE ST 334-1:2015, "Vertical Ancillary Data Mapping of
Caption Data and Other Related Data". Section numbers in parentheses
refer to the standard. The PDF (`st0334-1-2015.pdf`) is gitignored.
The CDP payload itself is digested in [`334-2.md`](./334-2.md).

## 1. Packet format (section 5)

Each packet is a SMPTE ST 291-1 type 2 ANC packet:

```
ADF (000h 3FFh 3FFh)  DID  SDID  DC  UDW[DC]  CS
```

* All words are 10-bit. Each 8-bit data byte sits in b7..b0; b8 is
  even parity over b7..b0 and b9 = NOT b8 (section 5.2). The values in
  parentheses below include those parity bits.
* DC counts the UDW words; its b7..b0 hold the count (section 5.1).
* CS is the ST 291-1 checksum (9-bit, computed over 10-bit words). It
  has no 8-bit representation; 8-bit carriage such as MCC / ST 436
  8-bit sample coding does not carry it.

## 2. Assigned services (section 5.1, Table 1)

| Service | DID | SDID | DC |
|---------|-----|------|----|
| CEA-708 closed captioning (CDP, ST 334-2) | 61h (161h) | 01h (101h) | variable: the CDP length |
| CEA-608 data (Annex B) | 61h (161h) | 02h (102h) | 3 (203h) |

* The CDP form (61h/01h) is preferred in all cases and is mandatory at
  frame rates other than nominal 30 / 60 (note under Table 1).
* DID 62h with SDID 01h / 02h / 03h is assigned to program
  description, data broadcast and VBI data (Table 2); not used here.
* For a CDP the UDW is the whole CDP, so DC equals `cdp_length`
  (section 5.3.1).

## 3. Placement (section 4)

* One line of the vertical ancillary space, from two lines after the
  RP 168 switching line to the last line before active video.
* Interlaced: caption packets go in the first field only. Progressive
  segmented frame: first segment only. Progressive: in the frame.
* HD: carried in the Y stream.
* Receivers select by DID / SDID, not by line number.

These matter only when inserting into SDI; an MCC line records the
line number, if at all, in its timecode suffix (see `mccdec.c`).

## 4. Annex B: 608-only ANC packet (61h/02h)

UDW = LINE byte + the two 608 bytes for one field. LINE b7 is the
field (1 = field 1, 0 = field 2), b6..b5 are 0, b4..b0 the line offset
from the format's base line. The CDP is the preferred carriage; the
encoder does not emit this form.
